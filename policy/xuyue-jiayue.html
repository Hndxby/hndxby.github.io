合约类别
终端购机合约：预存 0% / 50% / 100%（单品为100%） · 续约加约：全预存 / 部分50% / 免预存 · 单宽按「套餐档次」计费

术语与口径说明

存量用户（在网≥6个月） 新老用户均可 合约期 36期 随翼选 · 竞品 · 平 单宽 · 包年及以上
  • 合约到期续约（平迁）：原终端合约到期后，续约办理与当前同档的套餐并重签合约。
  • 升一档 / 升两档：续约或加约时，办理比当前套餐高一档 / 高两档的套餐档位。
  • 无约加约：在网但当前没有终端合约的用户，新签终端合约（加约）。
  • 终端补贴额度：办理时可用于终端购机抵扣的补贴金额，按「续约前套餐 → 需办理套餐」逐档对应。
  • 预存话费（三选一）：全预存＝终端补贴额度；部分预存＝补贴额度的50%；免预存＝0元。
  • 用户所得终端（二选一）：普通组可选手机或智慧终端；FTTR组为手机或智慧终端 + FTTR主从光猫 + 云盒。
  • FTTR组：随终端附赠 FTTR主从光猫 + 云盒的销售品组，补贴额度与普通组不同，办理时注意区分。
  • （平）：销售品名称后缀标签，用于与后台销售品名称核对。
  • 单宽用户：仅办理单宽带（不与手机融合）的用户；资费按「主套餐带宽 × 可选包」执行，费用以卡片「套餐档次」为准（如 360/年 即 360 元包年包）；云电视功能使用费与调测费等其他费用见单宽分区说明。
  • 销售品ID / 方案编号：受理时用于与后台系统核对，见各卡片底部备查信息。
  • 存量用户：在网 6 个月及以上的老用户；具体在网时长等受理条件以销售品受理规则为准。
  • 暂未上线：该销售品ID后台暂未开放受理，以实际上线情况为准。
  • 节点月租：终端购机类合约中，合约期内每月在套餐之外另行加收的月租（元/月）；为 0 表示不加收。
  • 直降金额：购买终端时从机价中直接抵扣的金额，按套餐档位一一对应（终端购机类合约）。
  • 随翼选 / 竞品 / 平：终端购机类合约销售品后缀标签，用于与后台销售品名称核对。
  • 预存比例（终端购机类）：融合合约支持首次预存 0% / 50% / 100%；单品积分预存合约为 100% 预存（预存金额与直降金额相等）。
  • 附加包：部分终端购机合约需同时订购指定附加包业务，见卡片中的橙色提示。
